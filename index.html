Things I've built

Flagship · Founder

Kiakia

Same-day bike delivery for online sellers in Nigeria, launching in Lagos. I designed and built the whole platform myself.

  • Customer and rider apps for iPhone and Android (React Native, Expo), with booking, live GPS tracking on Google Maps and a pickup and delivery code at every hand-over.
  • Smart dispatch: nearest riders first, a head start for favourite riders, first to accept wins, valuable parcels only for proven riders, and automatic pauses for unreliable riders.
  • iPhone Live Activities and Dynamic Island, push notifications and in-app voice calls between customer and rider.
  • TypeScript and Node API on Vercel with PostgreSQL, plus an admin dashboard for rider checks and live orders.
  • Security built in: hashed passwords, rate-limited logins, session revocation, private photo storage with expiring links, and a strict CSP.
